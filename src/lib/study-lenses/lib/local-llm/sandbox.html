local-llm sandbox

Eyeball-tests the device-local LLM runtime end-to-end in this browser. Generation is local-only: a model’s weights are fetched once from the HuggingFace CDN (hundreds of MB–GBs), cached, and reused offline thereafter. Nothing you type leaves the device. WebGPU is required for the real download/run path — if you have no GPU, use fake caps below to exercise the pure selection core with zero network. See the troubleshooting table at the bottom if a download is blocked.
