                note: some tokens have not corresponding ast nodes. "The key structural observation: leaf AST nodes (Identifier, Literal) correspond 1:1 with tokens, but interior nodes span multiple tokens, and some tokens — operators, punctuation, keywords — have no corresponding AST node at all. They're either absorbed into the parent node's type (a BinaryExpression implies there's a + somewhere) or stored as a plain string field (operator: "+"). \n This is the gap that makes source maps and tools like Recast non-trivial — you can go from AST node → source range trivially, but going token → AST node requires the containment query, and some tokens simply don't map to any named node."
