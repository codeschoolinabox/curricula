## Style / voice constraints (carried from prior + sharpened)

- **Reign in wannabe-GEB.** Don't write to impress fellow intellectuals. Write
  to teach.
- **Light and fun.** "It's supposed to stay light and fun to keep the learner
  engaged."
- **Belgian-French / Flemish skepticism with factual directness.** No
  enthusiasm-overselling.
- **Don't soften corrections.** When the user corrects, complete the cut.
- **Beware lazy conflations** (this session lock — user, R3). Concepts with
  surface similarity often aren't the same operationally.
- **Authority is plural.** No autobiographical sections; no "I" claims; no "my
  method" framing.
- **Avoid AskUserQuestion forms during live prose iteration.**
- **Mermaid only when relationships need it.** Otherwise tables, lists, prose,
  simple ASCII.
- **Un-prose-y style** for `syllabus.ontology.md`. Tables / lists / diagrams /
  `<details>` visuals. Reason: compact reference + transitional artifact toward
  visuals as load-bearing.
